# Ebook Corner

crea un mini sito di nome ebooks, formato vetrina, super moderna e super confortevole, template minimalista, dove venda gratuitamente degli ebook formato pdf scricabile  sul pc , tablet, telefono oppure trasferire sul kindle da leggere, al cliente, i libri possono essere letti direttamente dal sito, quindi metti in ciascuno il pulsante leggi ora, sopratutto in ciascun ebook metti la copertina ben visibile al cliente .
